Bioma Icons

Every glyph drawn for the shell, at construction size. Icons are the one graphic alphabet in Bioma that is not an indicator: they say what something is, never how hard it is working. All of them stroke currentColor, so a parent's colour is the icon's colour.

Construction

Geometry

  • 24 grid, 20 live area — two pixels of margin per side, so glyphs of different bulk weigh the same in a row.
  • Stroke 1.5, round caps and joins. Exceptions only where a glyph must read darker at small size (bell 1.6, search and edit 1.7, pause 2.6, error 2.0).
  • Corner radius 3 on rectangles: below it disappears at 16 px, above it turns into a pill and changes meaning.
  • No fills, except nodes (r 1.1–1.5) and glyphs that stand for a filled state, such as stop.
  • Must survive 16 px. If a detail vanishes there, remove it at 24 too: an icon with two versions is two icons to maintain.

Use

  • Primary gradient when the icon is a header, an active control, or the only content of a cell.
  • Muted text when it is inactive, secondary or a fallback. Never a state colour: an icon measures nothing.
  • Application icons are third-party and follow none of these rules. They sit in a dark circle with a thin outline, which is what makes them a family despite their styles.
  • The mark appears in the settings cell only. It is built from this set, but it is not an interface icon and is not reused elsewhere.
  • The wireless glyph is ours — two nodes joined by a thread. The Bluetooth mark is registered and is never reproduced.

The set

Each card shows the glyph at 24 px and at 16 px, its file name in the handoff package, and where it is used. Open SVG to copy the source.

Stroke weights in use

WeightGlyphsWhy
1.4workspacestwo long horizontal bars; at 1.5 they close up at 16 px
1.5the default — 22 glyphsthe weight the whole set is drawn at
1.6bell, app-fallback, chevrons, plus, closesmall or sparse shapes that need a touch more presence
1.7search, edit, sound-on, sound-offglyphs that sit inside dense rows
2.0 – 2.6error, pausedeliberately heavier: one is an alert, the other reads as a solid state
